# BookMyShow Microservices Backend

A movie ticket booking backend built using Java, Spring Boot, and Microservices.

## Technologies
- Java 17
- Spring Boot & Spring Cloud
- Microservices
- Eureka Server
- API Gateway
- Spring Security & JWT
- MySQL & JPA
- REST APIs

## Features
- Movie booking
- User authentication
- Secure REST APIs
- Service discovery
- Payment and email services
